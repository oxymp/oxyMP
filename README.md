# oxyMP

> A modern multiplayer platform for Grand Theft Auto V.

**oxyMP** — это разрабатываемая с нуля мультиплеерная платформа для **Grand Theft Auto V**, ориентированная на высокую производительность, модульную архитектуру и удобство разработки серверов и игровых ресурсов.

Проект находится на ранней стадии разработки.

---

## 🚧 Статус проекта

> **В активной разработке.**

На данный момент ведётся проектирование архитектуры и реализация базовых компонентов системы.

README будет регулярно обновляться по мере развития проекта.

---

## 🎯 Цели проекта

* Современная модульная архитектура
* Высокая производительность
* Масштабируемый игровой сервер
* Кроссплатформенный сервер (Windows / Linux)
* Простая система разработки игровых ресурсов
* Удобный SDK
* Максимально чистый и поддерживаемый код
